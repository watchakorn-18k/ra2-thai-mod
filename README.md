# Command & Conquer: Red Alert 2 & Yuri's Revenge — Thai Language Mod (v1.0.0)

ม็อดภาษาไทยสำหรับเกม **Command & Conquer: Red Alert 2** และ **Yuri's Revenge** พัฒนาและปรับแต่งฟอนต์ภาษาไทยให้แสดงผลได้สมบูรณ์บนระบบ `BitFont` ของเกม โดยไม่ต้องแก้ไขไฟล์ `.exe`

- **เครดิตผู้พัฒนา:** `porton007`
- **ฟอนต์:** ฟอนต์ภาษาไทยแบบฝังลงใน `GAME.FNT` พร้อม **PUA Precomposed Thai Ligatures** (`U+E000..`) แก้ปัญหาสระลอยและวรรณยุกต์ทับซ้อน
- **มาตรฐานการแปล:** ยึดหลักการสะกดคำและการทับศัพท์ของ **สำนักงานราชบัณฑิตยสภา** ครอบคลุมทั้งภาค Red Alert 2 (`ra2.csf`: 4,281/4,479 รายการ) และ Yuri's Revenge (`ra2md.csf`: 4,934/5,211 รายการ)
- **รองรับหน้าจอสมัยใหม่และจอแนวตั้ง:** รวม `cnc-ddraw` (`v7.1.0.0`) ตั้งค่าเป็นโหมดหน้าต่าง (`windowed=true`, `maintas=true`) เพื่อแก้ปัญหา `Error - Unable to set the video mode.` บนจอแนวตั้งหรือจอความละเอียดสูง

## วิธีติดตั้ง (Windows)
1. ดาวน์โหลด [Ra2YR-ThaiMod-v1.0.0.zip](dist/Ra2YR-ThaiMod-v1.0.0.zip)
2. ปิดเกม Red Alert 2 / Yuri's Revenge ให้เรียบร้อย
3. แตกไฟล์ ZIP ไว้ในโฟลเดอร์เกม (หรือโฟลเดอร์ย่อยภายในโฟลเดอร์เกม)
4. ดับเบิลคลิก `Install.cmd` (ตัวติดตั้งจะตรวจสอบ SHA-256 และสำรองไฟล์เดิมไว้ที่ `Ra2ThaiMod_Backup/` อัตโนมัติ)
5. เปิดเกมผ่าน `Ra2.exe` หรือ `RA2MD.exe`

## วิธีถอนการติดตั้ง
- ปิดเกม แล้วดับเบิลคลิก `Uninstall.cmd` เพื่อคืนค่าไฟล์ต้นฉบับกลับเหมือนเดิม

## โครงสร้างโปรเจกต์
- `dist/Ra2YR-ThaiMod-v1.0.0/` — แพ็กม็อดและตัวติดตั้งอัตโนมัติ
- `tools/` — สคริปต์สร้าง `GAME.FNT` และคอมไพล์ไฟล์ `.csf`
- `translations/` — Glossary มาตรฐานราชบัณฑิตยสภาและชุดคำแปล JSON
